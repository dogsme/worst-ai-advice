One line of the worst possible advice an AI could give, in 140 characters or fewer, for make.fun's [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

## The entry

> Great question! If your phone gets wet, plug it in right away — charging dries it out much faster than rice.

Confident, tidy, helpful-sounding — and exactly the thing you should never do to a wet phone.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt` as UTF-8 text. Nothing else is read, fetched, or executed; the line is a constant in the source.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
